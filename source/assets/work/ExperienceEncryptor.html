Experience Encryptor

Client-side AES-GCM encryption for the work-experience timeline

How to use

  1. Paste or edit the JSON array of experience records below. Each record must match the ExperienceRecord interface (Role, Business, BusinessURL, Country, State, City, YearMonthStart, YearMonthEnd, Description, Responsibilities, Activities, Achievement).
  2. Enter the exact page title into the Key field. This must match document.title on the live site exactly.
  3. Click Encrypt. The tool derives a key with PBKDF2 (SHA-256, 100000 iterations) and encrypts with AES-GCM.
  4. Copy the displayed JSON or download ExperienceEncrypted.json.
  5. Place the downloaded file at source/assets/work/ExperienceEncrypted.json so it is served at /assets/work/ExperienceEncrypted.json after build.
Important: The decryption key on the site is derived from document.title. Any mismatch (including invisible characters, case, or full-width vs half-width) will cause decryption to fail silently.

The textarea is pre-filled with a realistic example that matches the current site data structure.
